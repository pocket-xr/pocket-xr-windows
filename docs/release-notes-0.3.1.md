# Pocket XR for Windows 0.3.1

- **VITURE Beast with USB id 35CA:1201** is now recognised as a Beast, like the 35CA:1211 Beast testers have used. A
  tester's Beast on Android reported the 1201 id and was treated as unknown VITURE glasses; Windows had the same check.
  Not yet tried on a 1201 on a PC: if you have one, **Send logs to Mike** in the menu helps a lot.

Everything else is as in 0.3.0 (Steady mode's screen gap, Steady mode remembered) and 0.2.0 (hand tracking).

## Install

1. Download `PocketXR-Windows-0.3.1.zip` and unzip it anywhere (over an older version is fine: your settings are kept).
2. Open `PocketXR.exe`. It is not signed yet, so Windows may say "Windows protected your PC": choose **More info**,
   then **Run anyway**.
